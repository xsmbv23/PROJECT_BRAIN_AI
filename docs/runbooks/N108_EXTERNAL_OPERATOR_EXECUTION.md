# N108 External Operator Execution SOP

## Objective

Produce the first admissible runtime TransportReceipt for the exact live Render deployment without changing the probe or manufacturing evidence.

## Preconditions

- Exact runtime commit: `2d4415a875df3582aa26df4598f4f409c3c23027`
- Exact deployment: `dep-da2tjk7qj5pc738ht64g`
- Probe: `tools/transport_probe.py`
- Probe source must remain byte-for-byte unchanged.
- Operator must have an authorized command execution mechanism inside the exact Render container.

## Procedure

1. Confirm the running service corresponds to the exact deployment/commit.
2. Enter the exact live container using the authorized Render execution mechanism.
3. Execute only the existing `tools/transport_probe.py` primitive.
4. Capture stdout/evidence without modifying the receipt.
5. Verify the receipt contains only the approved compact fields.
6. Verify runtime identity binds the receipt to the exact deployment.
7. Submit the compact receipt to the Forensic admission path.
8. If any identity, hash, execution, or provenance check fails, stop and record DENY.

## Forbidden

- local substitution;
- proxy substitution;
- source/HTML hashing as runtime evidence;
- synthetic receipt;
- replayed receipt;
- editing the probe;
- editing the receipt after execution;
- broadening the endpoint into an arbitrary code execution facility.

## Success

Only a receipt generated by the exact live runtime can change:

`transport_runtime_execution = NOT_EXECUTED`

to:

`transport_runtime_execution = PROVEN`

and subsequently allow evaluation of the receipt gate.
