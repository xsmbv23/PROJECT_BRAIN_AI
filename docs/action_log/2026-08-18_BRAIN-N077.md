## Critical invariant

`bound=true` MUST NOT be promoted to `BOUND_TLS`.

It proves only that the runtime received a PostgreSQL-shaped binding. It does not prove:

- that the secret was resolved through the intended Render Secret Environment mechanism;
- that TLS admission is safe;
- that the network origin is the authorized path;
- that a real database round-trip succeeded;
- that durable evidence can be written and read back with a matching SHA-256.

This is the canonical example of:

```text
PASS_IS_LOCAL_TO_GATE
PASS_IS_PREREQUISITE_ONLY
NO_PASS_INHERITANCE
```
