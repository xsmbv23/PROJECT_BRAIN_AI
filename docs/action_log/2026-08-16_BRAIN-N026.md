## Architectural rule

The Brain core must depend on an abstract durable-state boundary, not directly on Render/Postgres credentials or connection code.

Production adapter belongs at the runtime/deployment edge.

This prevents:

- credentials entering Brain source;
- database logic becoming circular authority;
- bulk data being pulled into Brain;
- Render UI becoming a persistence authority.

## Fosennic continuity

```text
Brain governance
      ↓
DurableStateStore interface
      ↓
Runtime adapter
      ↓
SINGLE durable authority
```

No second source of truth is created.
