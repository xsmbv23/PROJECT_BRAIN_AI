# BRAIN-N097 — Source Provenance Capture Foundation

## Objective

Establish the exact raw-provenance machinery required before canonical XSMB quorum can be promoted.

## Implemented

1. `contracts/source_registry.json`
   - Registered Minh Ngoc, Xo so Phonix, ketqua16.net, XSMB.com.vn, and Minh Ngoc legacy as candidates.
   - Registration explicitly does NOT mean verification or quorum.
   - All candidates start `pending` and `independence_status=not_proven`.

2. `docs/SOURCE_PROVENANCE_PROTOCOL.md`
   - Defines exact raw HTTP artifact receipt.
   - Defines incremental SHA-256.
   - Defines anti-ad collision identity.
   - Defines independence proof requirements.
   - Defines ordered execution and PASS locality.

3. `tools/source_provenance_capture.py`
   - Bounded streaming capture using 64 KiB chunks.
   - 32 MiB per-artifact ceiling.
   - Incremental SHA-256; no whole-response accumulation.
   - Captures HTTP status, content type, redirect chain, timestamp, raw bytes, raw hash, source identity.
   - Never stores credentials in receipts.
   - Never claims independence from domain names alone.

4. `tools/verify_source_registry.py`
   - Verifies registry structure and deny-by-default rules.

5. Tests for receipt safety and registry invariants.
