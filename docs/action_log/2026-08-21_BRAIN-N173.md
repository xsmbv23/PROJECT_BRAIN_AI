## Critical architecture decision

A remote website is an external dependency, not a Brain boot dependency.

```text
Brain boot
  -> local foundation checks
  -> local governance/security checks
  -> serve

N173 explicit admission action
  -> source identity
  -> network ownership
  -> lawful acquisition admission
  -> fresh evidence
  -> S1
```

This prevents a slow, blocked, changed, or unavailable website from taking the Brain offline. It also protects Render Free 512 MB availability by keeping acquisition artifacts outside the Brain runtime.
