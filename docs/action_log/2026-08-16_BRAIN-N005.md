# BRAIN-N005 — XSMB Data ↔ Brain Corridor Package

## Scope

Translate the existing XSMB data foundation contract into an explicit Brain communication boundary without moving canonical data ownership into Brain.

## Verified source contract

`xsmbv23/xsmb-quant/DATA_FOUNDATION_CONTRACT_V1.md` defines:

```text
RAW BYTES → SHA → FULL_27 VALIDATION → PROVENANCE
        → QUORUM ≥ 2 → CANONICAL
        → TAIL_27 DERIVATION
```

Legacy `Ket_Qua_Loto27.xlsx` is reconciliation-only.

## Architecture

```text
XSMB DATA
  ↓
VALIDATION
  ↓
CANONICAL
  ↓
SHARD / MANIFEST
  ↓
COMPACT EVIDENCE

SECURE CORRIDOR

BRAIN
```
