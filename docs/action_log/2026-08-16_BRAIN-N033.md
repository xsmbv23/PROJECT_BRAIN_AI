# BRAIN-N033 — Explicit Layer Graph Correction

## Critical correction

Review of the room-lock implementation found that requiring `source_layer == destination_layer == lock.layer` was too restrictive and contradicted the architectural requirement that movement between layers can exist through explicit corridors.

The lock model is corrected to use `allowed_layer_edges`.

Example:

```text
L0 --[ROOM_A_KEY + CAP_A]--> L1 ROOM_A
```

This transition is legal only because `(0,1)` is explicitly declared for ROOM_A.

Unlisted edges, reverse edges, or non-adjacent jumps remain DENY.

## Why this matters

Fosennic protection is not achieved by making all movement impossible. It is achieved by making every movement **explicit, directional, independently authorized, and auditable**.

Therefore:

- no implicit upward transition;
- no implicit downward transition;
- no cross-room key reuse;
- no master key;
- no wildcard layer access;
- no jump over a layer.
