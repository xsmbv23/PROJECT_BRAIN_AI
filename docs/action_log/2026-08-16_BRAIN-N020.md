# BRAIN-N020 — Brain Core Hardening Assessment

## Assessment

The Brain core does not need replacement. Its authority separation is correct:

```text
DATA/BUILD → evidence → BRAIN GOVERNANCE → governed decision → runtime/UI
```

Current foundation already defines explicit corridors, capabilities, nonce/freshness, lineage, evidence envelopes and append-only action continuity. fileciteturn325file0

## Required hardening before Layer 1

Added design contract: `docs/BRAIN_CORE_HARDENING_V1.md`.

Priority controls:

1. policy/version pinning;
2. short-lived capability leases;
3. two-phase decision state (`PROPOSED → VERIFIED → EFFECTIVE`);
4. terminal `QUARANTINED` state;
5. corridor/capability circuit breakers;
6. single clock/freshness authority;
7. schema registry with major-version fail-closed behavior;
8. tamper-evident append-only decision hash chain;
9. auditable recovery after restart;
10. central resource governor for the Render 512MB/1CPU boundary.

## Existing foundation that must remain

The three-plane authority model and no-circular-authority rule remain unchanged. fileciteturn324file0

Evidence remains metadata/reference based; hashes never equal correctness or promotion. fileciteturn326file0
