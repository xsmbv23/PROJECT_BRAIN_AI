# BRAIN-N064 — Acquisition Drift Repair / Forensic Gate Separation

## Finding

The Quant data-plane registry contained five sources, while the historical forensic crawler had a separate three-source hardcoded acquisition map. This was a source-registry → acquisition implementation drift.

## Safe repair recorded

The Quant Engine now declares acquisition routes in the authoritative source registry and the crawler derives its default source set from that registry. `ketqua16` and the existing `xsmb` adapter are wired into the main acquisition path. Contract tests prevent registered-source/adapter drift.

The Quant repository also explicitly marks `runtime/raw` as local ephemeral capture rather than durable forensic evidence.
