# BRAIN-N112 — Epistemic + Lineage Runtime Admission Gate

## Objective

Convert the locked baseline into executable admission semantics without confusing `NO_EDGE` with `NOT_PROVEN` and without allowing PASS inheritance.

## Implemented

Added:

- `core/runtime_admission.py`
- `tests/test_runtime_admission.py`

The runtime gate now explicitly distinguishes:

- `NOT_PROVEN` — evidence/lineage is insufficient or prediction freeze is absent.
- `TEMPORAL_VIOLATION` — feature input is not strictly T-1 or earlier.
- `PROVEN_LINEAGE` — lineage is valid and only the next gate becomes eligible.

The gate also enforces:

```text
ONLY_EVIDENCE_CAN_SATISFY_EVIDENCE_CLAIM
PASS_IS_LOCAL
NO_PASS_INHERITANCE
UNKNOWN_IS_NOT_PASS
NO_LINEAGE_PROOF => EXECUTION_CANCEL
MAX_FEATURE_INPUT_DATE < PREDICTION_DATE
PREDICTION_FREEZE BEFORE RESULT_REVEAL
```

## Critical semantic boundary

N112 does **not** implement an Edge verdict.

Therefore it must never convert an epistemic admission result into:

```text
NO_EDGE
EDGE_CONFIRMED
EV_POSITIVE
PREDICTION_CONFIRMED
```

Those belong to later Quant/Edge gates and require their own evidence.

This is intentional. A valid lineage proves provenance, not profitability.
