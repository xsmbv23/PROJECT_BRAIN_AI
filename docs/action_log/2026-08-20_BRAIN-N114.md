# BRAIN-N114 — ACTION_RECEIPT Admission

## Purpose

Formalize the missing evidence gate without promoting any downstream truth.

## Contract

`contracts/action_receipt_v1.json`

The receipt proves exactly one proposition:

> one exact runtime action was executed for one exact commit and one exact deployment.

Required identity:

- action_id
- commit_sha
- deployment_id
- execution_nonce
- evidence_sha
- issued_at

The verifier rejects missing, malformed, stale, future, wrong-action, wrong-commit, wrong-deployment, wrong-evidence, and wrong-nonce receipts.

Freshness window: 900 seconds.

## Non-inheritance

`PASS_LOCAL` from ACTION_RECEIPT does not satisfy:

- SOURCE_INDEPENDENCE
- NETWORK_ORIGIN_PROOF
- CANONICAL_QUORUM
- TRUTH_ADMISSION
- EDGE
- EV/P&L
- global PROMOTION

The verifier is explicitly forbidden from issuing its own receipt. The receipt issuer belongs to the runtime execution boundary.
