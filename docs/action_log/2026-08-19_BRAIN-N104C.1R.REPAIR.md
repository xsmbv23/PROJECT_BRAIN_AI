# BRAIN-N104C.1R.REPAIR — Action Receipt Schema Drift

## Trigger

The exact-current intended commit `a1bf6f813c613edcdff638f5db831af7c9716c02` failed to become LIVE. The previous LIVE commit was `1b337d9e3ad2a9d44fb60d678084f92430c4f80d`. Therefore N104C.1R remained BLOCKED and no transport evidence was inferred.

## Root cause found during repair inspection

The canonical state schema uses:

```text
last_action_id
next_action_id
```

The newly introduced action receipt validator expected legacy aliases:

```text
last_action
next_action
```

That is a schema drift in an evidence gate and is unsafe to ignore.

## Repair

Changed `tools/action_receipt_validator.py` to require the canonical `*_id` state pointers and deliberately reject legacy pointer names as production evidence.

Updated `tests/test_action_receipt_validator.py` to use the canonical schema and added a regression test proving legacy pointer names are denied.
