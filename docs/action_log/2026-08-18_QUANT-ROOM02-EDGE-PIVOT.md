# QUANT-N003 — Pivot to Mathematical Edge Research

## Decision

The project must not confuse governance completeness with quantitative success.

The Brain remains the immutable Forensic control plane, but it must not consume the entire development budget while the Quant Engine has not yet demonstrated a measurable out-of-sample edge.

Therefore Layer 1 research is now active while Brain governance remains frozen.

## Separation of duties

```text
Project_Brain_AI
  = governance / admission / persistent successor memory / forensic evidence

Quant_Engine
  = mathematical research / feature extraction / signal testing / EV measurement

Chat
  = communication only
```

The Brain does not calculate the edge. The Quant Engine does not rewrite Brain governance.
