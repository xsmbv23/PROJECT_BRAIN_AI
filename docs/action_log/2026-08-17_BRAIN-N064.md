# BRAIN-N064 — Forensic State Machine + Reality Boundary

## Objective

Preserve the clarification that database forensic states are ordered gates in one admission chain—not independent PASS systems—and that Brain/Chat cannot manufacture the external event required for a transition.

## Canonical chain

```text
DB_EXISTENCE
    -> DB_BINDING
    -> DB_TLS_ADMISSION
    -> DB_ROUND_TRIP
    -> PROMOTION
```

Each PASS is local to its gate. No PASS is inherited by a later gate.

```text
PASS(Gate_n) -> evaluate(Gate_n+1)
```

Never implement:

```text
DB_EXISTS -> DB_ACCESS = PASS
DB_BOUND_TLS -> PROMOTION = PASS
```

## Reality boundary

```text
CHAT / BRAIN
    -> define / govern / validate
REAL EXTERNAL EVENT
    -> observation
    -> receipt
    -> state transition
```

`EXTERNAL_EVENT_CANNOT_BE_MANUFACTURED = TRUE`.

A commit, deployment, synthetic trigger, replayed receipt, copied observation, fixture, or chat assertion cannot substitute for the required real external event.

## WAIT_EXTERNAL_EVENT

When internally valid work is exhausted and a required external event has not occurred, `WAIT_EXTERNAL_EVENT` is the correct terminal state for the current evidence set.

It is not a bug, incomplete FSM, or permission to bypass the gate.

## Machine authority

```text
STATE / MACHINE AUTHORITY
        ↓
DOCTRINE / NORMATIVE LAW
        ↓
ACTION BOUNDARY
        ↓
EXECUTION
        ↓
OBSERVATION
        ↓
RECEIPT
```

No lower layer may silently override a higher layer. Chat is an interface only.

## Security interaction

The corridor/room model remains mandatory:

```text
corridor_key + room_key + optional_inner_release
```

Each room has a distinct key. Protected rooms may require an inner release. Access to one room does not imply access to another room or permission to mutate room state.

## Permanent successor law

Full normative doctrine:

```text
docs/FORENSIC_STATE_MACHINE_DOCTRINE.md
```

Every completed action must leave a human-readable action log, machine-readable state update, explicit next action or `WAIT_EXTERNAL_EVENT`, evidence identity/hash where applicable, and an explicit statement of what is NOT proven.
