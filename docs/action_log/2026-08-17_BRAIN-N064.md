## Critical semantic clarification

A foundation/unit test may report `durable_round_trip=PASS`. That proves the adapter/test implementation only. It does **not** prove a live PostgreSQL durable-evidence round-trip.

Only the dedicated database admission chain can establish live durable DB capability.

## Permanent admission-chain doctrine

The chain is one ordered Forensic Admission Chain:

```text
DB_EXISTENCE
    -> DB_BINDING
    -> DB_TLS_ADMISSION
    -> DB_ROUND_TRIP
    -> PROMOTION
```

A PASS at gate N is only permission to evaluate gate N+1. It never inherits into a deeper PASS.

Never implement:

```text
DB_EXISTS -> DB_ACCESS = PASS
```

or:

```text
DB_BOUND_TLS -> PROMOTION = PASS
```

Correct semantic rule:

```text
PASS(Gate_n) -> evaluate(Gate_n+1)
```
