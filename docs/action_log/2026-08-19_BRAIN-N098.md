## Critical doctrine applied

N098 is **not** marked PASS merely because the same numbers are visible on other websites.

`CAPTURE_CAPABILITY != CAPTURE_SUCCESS != EVIDENCE_VALID != CANONICAL_ADMITTED`.

Likewise:

- different hostname alone is not independence proof;
- a matching result alone is not independence proof;
- a search-engine observation is not a retained raw artifact;
- an alternate website is not an allowed fallback source unless predeclared before execution;
- `current_state.json` cannot be used as proof of the state it declares;
- `READY`/`ACTIVE` are execution states, never evidence;
- UNKNOWN/NOT_PROVEN is DENY, not PASS.
