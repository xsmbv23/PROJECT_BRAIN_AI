## Objective

Prevent successor Bots from treating database existence, service authorization, TLS admission, round-trip proof, and promotion as the same state.

## Forensic semantics

There is exactly one Forensic system. The database admission chain is a sequence of gates inside it, not separate Forensic states or independent security systems.

```text
DB_EXISTENCE
   -> DB_BINDING
      -> DB_TLS_ADMISSION
         -> DB_ROUND_TRIP
            -> PROMOTION
```

A PASS at an earlier gate cannot promote a later gate. Unknown is not pass. Any failure stops the chain.
