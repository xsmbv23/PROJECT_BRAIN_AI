# BRAIN-N025 — Durable Audit-Head Envelope

## Status
IMPLEMENTED / VERIFICATION PENDING

## Added

`core/durable_audit.py`

The module creates a compact, tamper-evident audit-head envelope containing only:

- envelope version;
- policy/schema/Brain-state versions;
- current audit head;
- previous audit head marker;
- event count;
- generation timestamp;
- envelope SHA.

It provides strict restore verification for hash, policy versions, expected audit head, and event count.

## Fosennic boundary

This envelope is metadata/reference only. It is NOT canonical XSMB data, does not store bulk historical data, and does not create a second truth authority.

## Required verification

A simulated restart must serialize the envelope, destroy the in-memory chain, restore the envelope, and verify the restored head. Tampering and policy mismatch must DENY.
