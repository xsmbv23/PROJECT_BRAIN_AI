# BRAIN-N072 — Admission Chain Serialization Repair

## External evidence

The repaired state-schema deployment passed `state_consistency` but Foundation still returned `DENY`.

Exact Render evidence:

```text
runtime_boot_gate = DENY
failed = foundation
state_consistency = PASS
foundation tests = 64 tests
errors = 6
```

All six errors had the same root cause in `tools/database_admission.py`:

```text
AttributeError: 'tuple' object has no attribute 'value'
```

The failing expression attempted to serialize the already-paired gate tuples as though they were Enum objects.

## Repair

Changed only the serialization expression:

```text
checks -> [(Gate, bool), ...]
chain  -> [gate.value for gate, _ in checks] + [Gate.PROMOTION.value]
```

The admission semantics were not changed.
