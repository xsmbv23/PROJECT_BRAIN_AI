# BRAIN-N015 — Restart-Safe Evidence Handoff

## Objective

Make runtime evidence survive Render restart/redeploy without storing bulk payloads in Brain/UI memory.

## Contract

Runtime evidence is a compact envelope containing identifiers, hashes, resource observations, status, and lineage. It must not contain the source workbook or full historical dataset.

```text
Render worker
  -> compact evidence envelope
  -> deterministic evidence hash
  -> persistent evidence store
  -> Brain index
  -> audit lookup
```

## Restart invariant

A container restart must not change:

- source SHA;
- fixture SHA;
- FULL_27 hash;
- TAIL_27 hash;
- manifest identity;
- evidence identity;
- promotion decision.

If persistent evidence is unavailable, the state is `PENDING/DENY`; never reconstruct silently from runtime memory.

## OOM invariant

512 MB is the platform hard boundary. 320 MB is the conservative guard. Crossing the guard is `DENY_MEMORY_GUARD`; repeated retries are forbidden until the execution boundary is changed.

## Promotion

Runtime evidence alone never promotes a single-source fixture. Quorum remains required.

`source_count=1 -> DENY`.

Layer 1 and staircase remain locked.
