# BRAIN-N037 — Complete Security Chain Verification

The foundation now contains four independent security concepts:

1. Corridor sensor — observation/warning only.
2. Room lock — unique room capability/key.
3. Directional layer edge — explicit corridor between layers.
4. Inner latch — second-person/authorized-inside release for protected rooms.

These are intentionally not merged into a single permission object.

## Required security separation

```text
SENSOR
  ↓ observation
AUTHENTICATION
  ↓ identity/key/capability
REQUEST AUTHORIZATION
  ↓ allowed corridor + directional edge
INNER LATCH
  ↓ authorized occupant release
ENTRY
```

No earlier stage may impersonate a later stage.
