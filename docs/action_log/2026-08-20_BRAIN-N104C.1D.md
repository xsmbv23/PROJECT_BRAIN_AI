# BRAIN-N104C.1D — Exact-Runtime Execution Primitive

## Purpose

Convert the previously blocked source transport execution into an auditable runtime action without bypassing the Forensic FSM.

## Important correction

An execution endpoint does **not** unlock the whole system.

It unlocks only the single currently admitted Room 01 action:

```text
DATA_ADMISSION
    -> RUNTIME_PROVENANCE_EXECUTION
```

All downstream gates remain independently locked.

## Implementation

The live Brain HTTP boundary now contains:

```text
GET /forensic/run-transport-probe
```

The endpoint:

1. requires `X-Forensic-Probe-Token`;
2. compares the token with a Render Secret Environment value using constant-time comparison;
3. executes the existing `tools.transport_probe.run_probe()` inside the service container;
4. returns only the compact `TransportReceipt`;
5. never returns raw HTML/body content;
6. does not parse advertisements or source semantics;
7. does not mutate canonical truth;
8. does not unlock Layer 1 generally;
9. does not unlock the staircase;
10. does not promote source truth.

The probe source itself remains unchanged and preserves its bounded raw transport behavior.

## Forensic gate position

```text
SOURCE_INDEPENDENCE
        ↓
NETWORK_ORIGIN_PROOF
        ↓
RESULT_TRANSPORT  ← current admitted execution
        ↓
```

The transport receipt is evidence for the `RESULT_TRANSPORT` gate only.

## Security

The capability token is stored only as a Render Secret Environment value. It is not stored in GitHub, action logs, repository files, or receipts.
