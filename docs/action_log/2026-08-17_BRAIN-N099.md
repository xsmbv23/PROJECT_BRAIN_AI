## Canonical doctrine

The database admission chain is one forensic FSM:

```text
DB_EXISTENCE
    -> DB_BINDING
        -> DB_TLS_ADMISSION
            -> DB_ROUND_TRIP
                -> PROMOTION
```

A PASS is **local to its gate**.

A PASS is a **prerequisite for the next gate**, never an inherited PASS.

Therefore:

```text
DB_EXISTS = PASS
    does NOT imply
DB_BOUND = PASS

DB_BOUND = PASS
    does NOT imply
DB_TLS_ADMISSION = PASS

DB_TLS_ADMISSION = PASS
    does NOT imply
DB_ROUND_TRIP = PASS

DB_ROUND_TRIP = PASS
    does NOT imply any future gate unless that gate has its own fresh evidence.
```

Unknown is not Pass. Default is Deny.
