# BRAIN-N104A — Source Evidence Adapter / FSM Domain Separation

## Trigger

The legacy scraper model was identified as incompatible with ONE_FORENSIC_FSM:
`fetch -> parse -> self-judge` is forbidden.

## Critical correction made

`core/forensic_gate.py` previously placed `NETWORK_ORIGIN_PROOF` inside the database admission chain.
That was architecturally incorrect because network-origin evidence belongs to the SOURCE domain.

Corrected chains:

```text
DATABASE DOMAIN
DB_EXISTENCE
  -> DB_BINDING
  -> DB_TLS_ADMISSION
  -> DB_ROUND_TRIP
  -> PROMOTION
```

```text
SOURCE DOMAIN
SOURCE_INDEPENDENCE
  -> NETWORK_ORIGIN_PROOF
  -> EXCEL_VS_WEB_MATCH
  -> CANONICAL_QUORUM
  -> TRUTH_ADMISSION
```

The two chains cannot inherit PASS from each other.

## Scraper migration

Implemented:

- `contracts/network_evidence_collector_v1.json`
- `docs/architecture/NETWORK_EVIDENCE_PIPELINE_V1.md`
- `tools/network_evidence_collector.py`
- `tests/test_network_evidence_collector.py`

The collector is an observer only.

It can produce:

- resolved IP;
- TLS version;
- peer certificate SHA-256;
- HTTP status;
- response SHA-256;
- capture timestamp;
- byte count;
- raw payload reference.

It cannot produce:

- canonical truth;
- PASS/FAIL content judgement;
- trading signal;
- prediction;
- risk decision;
- BUY/SELL.

## Source target

`https://ketqua16.net/` is the first explicit source target.

## Advertising

Ads, banners, tracking DOM, recommendation widgets and arbitrary visible text are
non-truth content. Future parsers must use selector allowlists and treat ambiguous
matches as UNKNOWN/HARD DENY.

## OOM

Network payloads are streamed in 64 KiB chunks and hashed incrementally.
No bulk historical payload is allowed to accumulate in Render memory.
