# BRAIN-N046 — Cross-Plane Privilege Verification

## Implemented

The full foundation verifier now includes `brain_governance_round_trip()`.

It proves:

- valid policy pin + schema major + scoped lease => only `ADMISSIBLE_FOR_NEXT_GATE`;
- expired lease => DENY;
- operation limit exceeded => DENY;
- Brain self-service destination => DENY.

The verifier therefore treats Brain as one gate in the security chain rather than as a privileged final authority.

No layer is allowed to infer authority merely because the previous layer returned PASS.
