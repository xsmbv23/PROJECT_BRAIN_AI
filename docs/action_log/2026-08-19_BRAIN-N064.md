# BRAIN-N064 — Pragmatic Ground-Truth + Network Evidence Collector

## Decision

The N01-N100 chain remains active and mandatory under Pragmatic Ground-Truth.
Pragmatic Ground-Truth is an admission strategy, not a replacement for the forensic foundation.

The legacy scrape model — scrape, parse, self-judge — is forbidden.

## Required interpretation

- N01-N040 validate doctrine and prevent circular validation.
- N041-N070 validate state authority and forensic FSM behavior.
- N071-N090 validate runtime trust and state-drift conditions.
- N091-N100 validate source identity and FULL27 completeness/shape.
- Excel may become the ground-truth anchor only after its own admission gate passes.
- `EXCEL_VS_WEB_MATCH` is a local comparison result and cannot inherit or grant unrelated PASS states.
- Canonical quorum remains a separate gate.
- The network collector is an observer only; it has no authority to declare canonical truth.

## Chain

```text
N01-N040
   -> doctrine
N041-N070
   -> state authority / FSM
N071-N090
   -> runtime trust / drift
N091-N100
   -> source identity / FULL27
EXCEL_GROUND_TRUTH_ADMISSION
   -> NETWORK_EVIDENCE_COLLECTOR
   -> NETWORK_ORIGIN_PROOF
   -> WEB_CANDIDATE
   -> EXCEL_VS_WEB_MATCH
   -> CANONICAL_QUORUM
   -> downstream admission
```

Every transition is local. No PASS inheritance.

## Network collector contract

Implemented in `contracts/network_evidence_collector_v1.json` and
`docs/architecture/NETWORK_EVIDENCE_PIPELINE_V1.md`.

The collector may emit only evidence such as raw-payload reference, timestamp,
HTTP metadata, resolved IP, TLS peer certificate hash, TLS version, response hash,
and transport status.

It may not emit `PASS`, `FAIL`, signal, prediction, risk decision, BUY, or SELL.

## Network origin proof

Minimum transport evidence:

1. resolved IP;
2. TLS version;
3. peer certificate SHA-256;
4. response SHA-256;
5. capture timestamp.

Missing evidence is `NOT_PROVEN` and therefore HARD DENY at that gate.

## Advertising rule

XSMB pages may contain advertisements, tracking elements, recommendation widgets,
and injected DOM. Visible text is not automatically evidence.

Result extraction must use an explicit selector allowlist. Ambiguous matches become
UNKNOWN and cannot be promoted.

`https://ketqua16.net/` is registered as the first explicit source target.

## OOM rule

Network payloads are streamed in 64 KiB chunks with incremental SHA-256. Bulk
historical payloads must never be accumulated in Render memory.

## Forensic invariant

`DB_EXISTS`, `DB_BINDING`, `DB_TLS_ADMISSION`, `DB_ROUND_TRIP`,
`EXCEL_GROUND_TRUTH_ADMISSION`, `NETWORK_ORIGIN_PROOF`, `EXCEL_VS_WEB_MATCH`,
and `CANONICAL_QUORUM` are distinct gates. A PASS in one never implies PASS in another.
