# BRAIN-N107 — Forensic Gate Non-Inheritance Standard

## Objective

Persist the architectural rule clarified during review: database/source gates are not separate Forensic systems. They are ordered gates inside ONE Forensic FSM.

## Normative rule

```text
PASS_IS_LOCAL
PASS_IS_PREREQUISITE_ONLY
NO_PASS_INHERITANCE
OWN_GATE_EVIDENCE_REQUIRED
UNKNOWN_IS_NOT_PASS
DEFAULT_DENY
```

Therefore:

```text
DB_EXISTENCE -> DB_BINDING -> DB_TLS_ADMISSION -> DB_ROUND_TRIP -> PROMOTION
```

is one admission chain, not five independent privilege domains.

Likewise source provenance is one chain:

```text
SOURCE_INDEPENDENCE -> NETWORK_ORIGIN_PROOF -> RESULT_TRANSPORT
-> OFFICIAL_RESULT_PANEL -> CANDIDATE -> EXCEL_VS_WEB_MATCH
-> CANONICAL_QUORUM -> TRUTH_ADMISSION
```

A gate PASS only makes the next gate eligible for evaluation. It never changes the next gate's state.

## Security model

Every gate behaves as a locked room:

```text
corridor_key + room_key + own_gate_evidence
```

Protected rooms may additionally require an inner-release action.
