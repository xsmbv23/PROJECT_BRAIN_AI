# REALITY-N011 — Runtime-Bound Source Identity

## Decision

The source identity is immutable as:

```text
SOURCE = (SOURCE_URL, EXECUTION_RUNTIME)
```

Therefore the same URL observed by Render, GitHub Actions, local machine, or another VPS is a distinct observation. Results MUST NOT be silently merged.

## Why

N010 demonstrated that the same source URL can be unreachable from one execution surface while an earlier receipt existed from another surface. The correct response is not to overwrite the failure, substitute a browser observation for a container observation, or fabricate bytes.

The system must test repeatability across execution surfaces.

## Implemented

1. Added `contracts/runtime_source_identity.json`.
2. Added `.github/workflows/reality_n011_runtime_receipt.yml`.
3. The workflow performs transport-only capture of `https://ketqua16.net/`.
4. It records only compact evidence: runtime, exit code, HTTP status, byte count, SHA-256.
5. It never parses, normalizes, maps, or claims domain truth.
6. Raw response is kept out of GitHub logs; only the compact receipt is uploaded as an artifact.
