# BRAIN-N028 — Deterministic Foundation Verification Runner

## Assessment

N028 required a single repeatable verification path instead of relying on separate manual checks. That seam is now closed.

## Added

`tools/verify_foundation.py`

The runner performs, in one bounded stdlib-only process:

1. discover and execute `tests/test_*.py`;
2. run the combined Foundation Gate;
3. scan repository text for obvious credential-like material;
4. inspect `core/*.py` for direct database/network adapter imports;
5. perform durable audit-head round-trip through the abstract store boundary;
6. record tracemalloc peak memory and elapsed time.

## Hard boundary

No network, Render credentials, Postgres connection, workbook or historical XSMB dataset is loaded by this verifier.

## Result semantics

A passing test suite alone is insufficient. The verification result requires the combined gate to PASS and the structural scans/round-trip to complete without assertion failure.
