## Exact failure evidence

```text

```

The same runtime also showed `state_consistency = PASS` and `state_drift = PASS`.

The repository contains immutable evidence receipts, but no receipt for `BRAIN-N104C.1` was found in the exact deployment tree. Therefore no receipt was manufactured.

## Architectural correction

The boot/liveness gate was incorrectly coupled to the historical action-receipt admission gate.

That coupling is now removed:

```text
SERVICE LIVENESS
    state consistency
    foundation integrity
    memory guard
    access path
          |
          +----> may boot HTTP service

FORENSIC ADMISSION
    action receipt
    exact commit match
    receipt SHA match
    state reconciliation
          |
          +----> may unlock transport/admission only when PASS
```

A missing historical receipt therefore remains `ADMISSION_DENY` but no longer causes Render to lose its HTTP port. This is not a weakening of evidence: the receipt gate still denies downstream admission and transport.
