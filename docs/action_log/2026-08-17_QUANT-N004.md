# QUANT-N004 — Data Pipeline Acceleration Doctrine

## Purpose

Preserve the frozen Forensic foundation while making N003 real-data acquisition faster and more observable. Speed must come from parallel accumulation, not relaxed admission.

## Frozen database admission semantics

There is exactly ONE Forensic database admission FSM, not multiple independent Forensic states:

```text
DB_EXISTENCE
  -> DB_BINDING
  -> SECRET_RESOLUTION
  -> DB_TLS_ADMISSION
  -> NETWORK_ORIGIN_PROOF
  -> DB_ROUND_TRIP
  -> PROMOTION
```

PASS is a prerequisite only. PASS never inherits forward. UNKNOWN is not PASS. The first FAIL/UNKNOWN makes later gates UNREACHED. `DB_EXISTS=PASS` never means the service has database authority. `BOUND_TLS=PASS` never means durable evidence round-trip passed. Only the corresponding gate evidence can advance the FSM.

## N003 acceleration rules

1. **Hybrid pull + push acquisition**: scheduled history pulls plus event-driven capture when a new business date is detected.
2. **Data Readiness Index**: `coverage * quorum_ratio * (1 - conflict_ratio)` is visibility only; it never overrides strict admission.
3. **Early Freeze Candidate**: >=7 contiguous days + quorum + no conflict may support ingestion/replay rehearsal only. It is never N003 proof truth.
4. **Incremental Canonical Freeze**: use a deterministic hash chain `Hn = SHA256(Hn-1 + day_hash_n)` to avoid rehashing the entire dataset. The canonical dataset is still one-way and immutable after strict admission.
5. **Parallel network collection** is allowed; semantic ordering must remain deterministic by business_date/source_id. Network parallelism must never alter canonical ordering.
6. **Quarantine zone**: conflicts and malformed source artifacts are preserved append-only and never silently merged into truth.
7. **Admission dry-run**: expose missing dates, missing quorum, conflicts and exact conditions that would be required for admission. Dry-run has zero promotion authority.
8. **No Silent Drift**: an already observed business date whose exact raw-response SHA changes is `DRIFT_DETECTED` and strict admission remains DENY.
9. **Snapshot pointer**: `canonical/latest.json` may point to an immutable canonical version, but the pointer itself never changes the canonical artifact and must retain prior pointer history.
10. **Hard boundaries remain**:

```text
BUFFER != ENGINE INPUT
PARTIAL != TRUTH
COLLECTION != ADMISSION
```

## Doctrine

> Speed comes from parallel accumulation, not relaxed admission.

## Resource rule

Render Free 512 MB is a hard boundary. Prefer bounded streaming, compact manifests, hash metadata and subprocess isolation. Never materialize the whole history merely to compute readiness.
