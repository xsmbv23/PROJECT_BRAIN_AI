## Evidence reconciled

1. real-source provenance
2. raw-byte SHA-256 evidence
3. sufficient consecutive real dates
4. `coverage_ratio == 1.0`
5. no unresolved source conflict
6. explicit admission receipt
7. frozen canonical hash

The directory currently exposes the contract/README, but the existence of that README is not evidence that an admitted canonical dataset artifact exists.


## Important anti-fabrication rule

Do NOT copy a few rows into GitHub and label them canonical.
Do NOT manufacture a canonical hash.
Do NOT treat an external observation as a runtime receipt.
