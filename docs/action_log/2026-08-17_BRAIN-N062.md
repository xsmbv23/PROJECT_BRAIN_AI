# BRAIN-N062 — Render Database Binding Boundary

## Implementation

Added `tools/binding_probe.py` and integrated it into the runtime boot evidence.

The probe is deliberately non-secret. It reports only:

- `NOT_BOUND`
- `DENY_SCHEME`
- `DENY_TLS`
- `BOUND_TLS`

It never emits the database URL, username, password, host, token, or any credential-derived value.

The runtime boot evidence now records the classification so a successor does not have to infer database binding from silence.

### Why this is a correct DENY

The system now knows the difference between:

```text
DATABASE EXISTS
        !=
SERVICE IS AUTHORIZED/BINDED TO DATABASE
```

The database is a separate secured room. Possessing the room's existence is not possession of its key.
