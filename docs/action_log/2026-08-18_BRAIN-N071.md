# BRAIN-N071 — Boot Gate Pointer Drift Repair

## External event

Render attempted to deploy the current Brain service and the runtime boot gate returned `DENY`.

Observed failure:

```text
KeyError: 'next_action_id'
```

The failure occurred in `tools/check_state_consistency.py` while reading `state/current_state.json`.

## Root cause

`state/current_state.json` contained the successor pointer as:

```text
next_brain_action = BRAIN-N070
```

but the mandatory machine-readable pointer expected by the boot verifier:

```text
next_action_id
```

was missing.

This is **state-schema drift**, not a reason to bypass the gate.

## Repair

1. Restored `next_action_id = BRAIN-N070` to `state/current_state.json`.
2. Restored/confirmed `ci_status = UNKNOWN_NO_OBSERVABLE_WORKFLOW_RUN`.
3. Hardened `tools/check_state_consistency.py` so missing required keys now produce an explicit `FAIL` instead of an uncontrolled `KeyError`.
4. Kept `promotion = DENY`.
5. Kept `layer_1 = ROOM_01_GATE_LOCKED`.
6. Kept `staircase = LOCKED`.
7. Kept `action_space = 0` and the mandatory no-op / wait-for-external-event policy.
