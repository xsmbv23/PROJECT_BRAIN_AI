# BRAIN-N055 — Runtime Scanner Fixture Failure / Repair

## Render evidence

On the N055 deployment, the anti-drift verifier passed and the integrated test suite reached:

```text
Ran 46 tests in 0.091s
OK
```

The boot gate still denied startup because `source_scan()` detected an intentional credential-pattern fixture in `tests/test_credential_guard.py`.

## Diagnosis

This is a false positive at the repository-level scanner boundary. The credential guard test intentionally contains forbidden examples so the credential guard itself can prove that it rejects them.

The source scanner is intended to inspect runtime source, not adversarial test fixtures or its own detector implementation.

## Repair

`source_scan()` now excludes:

- the verifier implementation itself;
- `tests/` fixtures;
- binary/archive suffixes already excluded.

The actual runtime credential guard remains independently tested by the 46-test suite.
