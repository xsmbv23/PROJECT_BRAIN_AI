# BRAIN-N012 — Render-Safe Bounded Execution

## Objective

Advance the bounded real-source verification without turning Render Free into a historical data-processing host.

## Source of truth

The existing real-source fixture is `xsmb-quant/fixtures/2026-08-12/full27_fixture.json` with source SHA recorded in its manifest. The fixture remains `VERIFICATION_ONLY` and quorum-denied.

## Implementation

Added:

- `xsmb-quant/verification/render_safe_runner.py`

The runner:

1. accepts exactly one fixture;
2. optionally receives the source artifact for SHA verification;
3. invokes the bounded verifier as a separate process;
4. records elapsed time and observed RSS;
5. applies a conservative guard below the 512 MB platform ceiling;
6. writes compact runtime evidence beside the verifier output;
7. never changes promotion state.

## Hard boundary

```text
Render Free hard ceiling = 512 MB / 1 CPU
Safety guard default     = 320 MB
```

The guard is deliberately below the platform ceiling. It is a policy threshold, not an assertion that the service can safely consume the remaining RAM.

## Runtime topology

```text
Brain/UI
   |
   +-- preflight
   |
   +-- ONE FIXTURE
   |
   v
render_safe_runner
   |
   +-- bounded verifier child
   |
   +-- compact runtime evidence
   v
Brain index/evidence
```

No historical workbook is loaded, no daily shards are concatenated, and no multiprocessing is introduced.

## Important limitation

This commit establishes the guard and execution boundary but does not claim Render runtime PASS until the deployed service/build boundary executes the runner and produces runtime evidence.

If observed memory reaches the guard, the job is DENY and must move to an external worker/build plane.
