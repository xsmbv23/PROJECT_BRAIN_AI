# BRAIN-N068 — Simplified Forensic Database Admission State Machine

## Decision

The database Forensic model is explicitly simplified into **one ordered state machine**, not multiple independent Forensic systems.

```text
DB_EXISTENCE
    -> DB_BINDING
    -> DB_TLS_ADMISSION
    -> DB_ROUND_TRIP
    -> PROMOTION
```

## Immutable rule

`PASS` at a gate is only a prerequisite for evaluating the next gate.

It is never inherited and never grants a deeper capability.

```text
DB_EXISTS PASS
    != DB_BOUND PASS

DB_BOUND PASS
    != DB_TLS_ADMITTED PASS

DB_TLS_ADMITTED PASS
    != DB_ROUND_TRIP PASS
```

Only a real compact metadata:

```text
WRITE -> READ -> SHA-256 MATCH
```

can satisfy the durable evidence gate.

## Implementation

Added:

- `tools/database_admission.py`
- `tests/test_database_admission.py`

The module intentionally contains only the admission state machine and no database credential handling. This keeps the rule small, deterministic, auditable, and easy for successor Bots to reuse.
