# BRAIN-N104C — Result Transport Boundary

## Trigger

N104B proved real network capture from `ketqua16.net`, but raw HTTP HTML contained the prize labels without the actual result numbers. Therefore capture was proven while content/candidate admission remained denied.

## Decision

Do not attempt Excel-vs-web matching yet. First identify the result transport.

The transport classifier now distinguishes:

1. `RAW_HTML_RESULT`
2. `EMBEDDED_JSON`
3. `SECONDARY_TRANSPORT_HINT`
4. `NO_RESULT_TRANSPORT_PROVEN`

The classifier is deterministic and dataset-free. It accepts supplied response text and performs no network access.

## Critical invariant

```text
CAPTURE_PROVEN
      !=
CONTENT_PROVEN
      !=
CANDIDATE_PROVEN
```

A transport hint is never a candidate.

A candidate may only be admitted from the **official result panel** after the collector has established the actual transport and captured the result-bearing content.

## Admission chain

```text
NETWORK_ORIGIN_PROOF
        │
        ▼
RESULT_TRANSPORT
 ├─ RAW_HTML_RESULT
 ├─ EMBEDDED_JSON
 └─ SECONDARY_TRANSPORT_PROVEN
        │
        ▼
OFFICIAL_RESULT_PANEL
        │
        ▼
CANDIDATE_ONLY
        │
        ▼
EXCEL_VS_WEB_MATCH
        │
        ▼
CANONICAL_QUORUM
        │
        ▼
TRUTH_ADMISSION
```

Any missing node is `DENY`; there is no inheritance of PASS across these gates.

## Scope separation

DB admission and Source admission remain separate FSM domains:

```text
DB_EXISTENCE → DB_BINDING → DB_TLS_ADMISSION → DB_ROUND_TRIP → DATABASE_PROMOTION

SOURCE_INDEPENDENCE → NETWORK_ORIGIN_PROOF → RESULT_TRANSPORT → OFFICIAL_RESULT_PANEL → CANDIDATE → EXCEL_VS_WEB_MATCH → CANONICAL_QUORUM → TRUTH_ADMISSION
```

A PASS from either domain cannot satisfy a gate in the other domain.

## Memory/OOM rule

The classifier is intentionally small, deterministic, and dataset-free so it cannot turn the Brain runtime into a bulk HTML/data-processing worker. Heavy capture/render/secondary-request work belongs outside Brain governance, in the source collector corridor.
