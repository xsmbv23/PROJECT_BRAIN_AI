# QUANT-N005-DOCTRINE-LOCK

## Decision

N005 semantic freeze is now a permanent inheritance doctrine.

## New mandatory invariants

1. Every invariant must reduce uncertainty of a specific named gate and be testable by evidence.
2. Readiness is observability only and has zero admission/promotion/execution authority.
3. Dry-run is a shadow, not a path. Its output is non-evidential.
4. One authoritative forensic FSM only.
5. PASS at one gate is only a prerequisite; there is no pass inheritance.
6. Unknown and unreached are not pass.

## Boundaries

```text
BUFFER != ENGINE_INPUT
PARTIAL != TRUTH
COLLECTION != ADMISSION
SIMULATION != EVIDENCE
READINESS != AUTHORITY
DB_EXISTENCE != DB_AUTHORIZATION
```

## Current position

Room 01 remains active only for real-source acquisition/readiness visibility. Canonical admission remains strict. Layer 1 promotion and staircase remain locked until their own evidence gates are proven.

## Successor requirement

A successor must read this doctrine before the next action and must record the specific gate uncertainty reduced by that action.
