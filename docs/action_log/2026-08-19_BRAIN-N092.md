# BRAIN-N092 — State Reconciliation Admission Boundary

## Purpose

N092 moves state reconciliation from a passive verifier into an explicit admission boundary.

The chain is:

```text
BRAIN_STATE
   ↓
QUANT_PROJECTION
   ↓
RUNTIME_EVIDENCE
   ↓
RECONCILIATION
   ↓
ADMISSION DECISION
```

## Immutable rules

- Brain `state/current_state.json` remains the single source of logical state truth.
- Quant projection is evidence/projection only; it is never authority.
- Render runtime is evidence only; it is never authority.
- Action logs are immutable history.
- Runtime commit equality is NOT required for logical state validity.
- Runtime commit drift is version/reconciliation evidence.
- Logical authority/protocol violations are `HARD_DENY`.
- Missing Quant projection evidence is `NOT_PROVEN`, never PASS.
- No PASS is inherited by a deeper gate.
- Default deny remains mandatory.

## Decision semantics

```text
VERIFIED
  = current gate has sufficient evidence

RECONCILE_REQUIRED
  = promotion/action must remain denied until explicit reconciliation

HARD_DENY
  = action is denied because authority/protocol integrity is broken
```
