# BRAIN-N100 — Network Origin Proof

## Gate

`NETWORK_ORIGIN_PROOF`

## Exact observation

Two declared source URLs were externally observed as reachable over HTTPS:

- `https://ketqua16.net/`
- `https://xsmb.com.vn/`

The observation confirms that both requested hosts currently expose lottery-result web content. `ketqua16.net` currently presents itself as KETQUA.NET and visibly contains XSMB/result content. `xsmb.com.vn` currently presents itself as XSMB.COM.VN and visibly contains XSMB result content.

## Critical Forensic distinction

This observation is **NOT canonical-source proof**.

It does not establish ownership, authoritative origin, or source independence. It also does not prove that a redirect target, CDN, mirror, or advertisement destination is the canonical truth source.

Therefore N100 must not promote either source to `PROVEN` merely because the requested URL returned web content.

## Advertisement boundary

Advertisements, promotional links, forum links, prediction pages, statistics pages, and other navigation content are outside the source-truth boundary. They are never allowed to become evidence merely because they appear on the same page.

## Decision

```text
REQUESTED_HOST_REACHABILITY      = OBSERVED
HTTPS_TRANSPORT                  = OBSERVED
SOURCE_CONTENT_PRESENT           = OBSERVED
CANONICAL_IDENTITY               = NOT_PROVEN
SOURCE_INDEPENDENCE              = NOT_PROVEN
SOURCE_TRUTH_CAPTURE             = DENY
CANONICAL_QUORUM                 = DENY
PROMOTION                        = DENY
ROOM_01                          = ACTIVE
LAYER_1                          = LOCKED
STAIRCASE                        = LOCKED
```

## Why this is correct

`PASS_IS_LOCAL_TO_GATE` remains mandatory:

```text
network reachable
      !=
canonical source proven
      !=
source truth admitted
      !=
canonical dataset admitted
```

No payload was admitted by N100.

## Next

`BRAIN-N101` — implement a Render-side bounded origin metadata probe and persist only compact non-secret transport evidence (status, final host, redirect chain, TLS transport metadata). The probe must remain incapable of source-truth capture and incapable of canonical promotion by itself.
